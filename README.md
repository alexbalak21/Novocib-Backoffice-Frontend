# Novocib Backoffice Frontend

Simple frontend for the Novocib backoffice built with Astro.

## Quick start

- Requirements: Node.js 18+ and npm or pnpm
- Install dependencies:

```bash
npm install
```

- Start dev server:

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Project structure

- `src/` — source files
  - `pages/` — Astro pages (e.g. `items.astro`)
  - `lib/` — utilities and GraphQL client
  - `types/` — TypeScript types

## Notes

- See `api_doc/stock_api.md` for API reference.
